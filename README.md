# Cancer Data Analysis | Exploratory Data Analysis & Inferential Statistics

## 📌 Project Overview

This project focuses on performing Comprehensive Exploratory Data Analysis (EDA) and Inferential Statistical Analysis on a Global Cancer Patient Dataset covering the period 2015–2024.

The objective is to analyze patient demographics, identify cancer-related patterns, explore relationships between different variables, and apply statistical methods to derive meaningful insights from the dataset.

## 🎯 Project Objectives

- Understand the structure and characteristics of the dataset.
- Perform data cleaning and preprocessing.
- Analyze patient demographics and age distributions.
- Explore cancer types and related patient characteristics.
- Identify trends and patterns within the dataset.
- Analyze relationships between numerical and categorical variables.
- Apply statistical hypothesis testing.
- Generate meaningful insights through data visualization.

## 📂 Dataset Information

- **Dataset Name:** Global Cancer Patients Dataset (2015–2024)
- **File Format:** CSV
- **Data Type:** Patient and cancer-related information.
